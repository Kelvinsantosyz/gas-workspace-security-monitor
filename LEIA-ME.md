# Comece aqui

1. Leia `GUIA.md`, sobretudo permissões e implantação.
2. Confira `MATRIZ_ALERTAS.md` com os 51 itens originais.
3. Copie os sete arquivos `.gs` e o manifesto de `src/` para um projeto Apps Script independente.
4. Configure as três propriedades e execute `prepararPlanilha`.
5. Configure domínios, valide conexões, homologue e instale os gatilhos.

O dashboard e as abas são criados pelo próprio Apps Script no Google Sheets. Nenhuma instalação no seu domínio foi realizada durante a preparação deste pacote.

Testes: `node tests/test.cjs`. Resultado: `VALIDACAO.md`.
